# Main Shell

## Display

- Main window: two-pane layout.
- Left pane: database browser.
- Right pane: editable playlist.
- Toolbar: previous, play-pause, and next controls.
- Status bar: current context plus elapsed and total time.
- Spectrum analyzer: titlebar accessory at the far right.

## Options

- Options: opens with `Command+,`.
- Options: utility window sized for preference editing.

## About

- About CocoaSpice: opens from the standard App menu.
- About: lists the external decoder and emulator projects used by the app, their purposes, license terms, and source links.
